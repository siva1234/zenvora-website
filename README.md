# Zenvora Technologies Website

## GitHub Pages deployment
1. Create a GitHub repository, e.g. `zenvora-website`.
2. Upload all files in this folder to the repository root.
3. Open **Settings → Pages**.
4. Choose **Deploy from a branch**.
5. Choose `main` and `/ (root)`, then Save.

## Before production
Replace the placeholder WhatsApp number (`+91 00000 00000`) and verify the email address.
The contact form is currently front-end only; connect it to an email/backend service before relying on it for enquiries.
